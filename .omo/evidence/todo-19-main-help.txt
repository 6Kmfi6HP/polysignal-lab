usage: main.py [-h] [--mode {scheduler,dashboard,smoke}] [--config CONFIG]
               [--dashboard] [--once] [--real-readonly-smoke]
               [--evidence EVIDENCE]
               [{scheduler,dashboard,smoke}]

PolySignal Lab runtime

positional arguments:
  {scheduler,dashboard,smoke}
                        Optional runtime mode command. (default: None)

options:
  -h, --help            show this help message and exit
  --mode {scheduler,dashboard,smoke}
                        Runtime mode to execute. (default: None)
  --config CONFIG
  --dashboard           Compatibility alias for --mode dashboard. (default:
                        False)
  --once                Run one bounded readiness pass instead of the
                        scheduler loop. (default: False)
  --real-readonly-smoke
                        Run bounded public read-only market, scheduler,
                        dashboard, and safety checks. (default: False)
  --evidence EVIDENCE   Optional path for bounded smoke evidence JSON.
                        (default: None)
