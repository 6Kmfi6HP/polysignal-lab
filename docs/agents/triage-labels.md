# Triage 标签

技能使用五个标准 triage 角色。此文件将这些角色映射到本仓库 issue 追踪器中实际使用的标签字符串。

| 技能中的角色 | 本仓库标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待 reporter 补充更多信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整定义，AI 代理可直接处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色（例如「应用 AFK-ready triage 标签」）时，使用此表中对应的标签字符串。

如需自定义，编辑右侧列以匹配你实际使用的标签名。
